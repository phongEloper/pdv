# PRELOADER

# 📜 Installation:
Get Preloader.lua file: [https://github.com/phongEloper/Preloader/releases/](https://github.com/phongEloper/Preloader/releases/)

# 💻 Usage:
1. Download the file from [Releases](https://github.com/phongEloper/Preloader/releases/).
2. Open **Windows Explorer** then drag the file and put into your game place.
3. Then drag the **Preloader** LocalScript into the **ReplicatedFirst** instance.
